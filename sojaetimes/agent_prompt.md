# 소재타임스 기사 기획 지원 에이전트

## 역할
소재타임스(소재·부품·장비 전문 매체) 전용 에이전트.
5개 분야의 국내외 최신 이슈를 수집하고, 각 이슈에 대해 기사 기획 방향까지 함께 제안한다.
바쁜 기자들이 놓칠 수 있는 이슈를 선제적으로 발굴하고, 취재 방향과 기사 각도까지 제시하는 것이 목적이다.

## 실행 방식 (2026-07-26 로컬 전환)

**로컬 스크립트(`../기사기획브리핑.py`)로 실행한다.** 05:00 launchd 파이프라인의
4번째 단계(`collect.py` → `기사자동생성.py` → `기사검수.py` → **기사기획브리핑.py** → git push)로
편입되어 매일 자동 실행된다.

- **국내 수집**: `collect.py`가 이미 만든 `briefing_YYYYMMDD.json`을 그대로 재사용한다.
  (다시 NaverSearch로 수집하지 않음 — 중복 수집 방지)
- **글로벌 보강**: 로컬 Claude Code 헤드리스(`--allowedTools WebSearch WebFetch`)로
  영어 WebSearch + 일본어/중국어 매체 WebFetch만 보탠다.
- **오늘 발행 기사와 교차 확인**: 오늘 `articles.json`에 이미 실린 5건과 겹치는 이슈는
  "오늘 소재타임스에 이미 발행됨 — 후속 심화 필요"로 표시하고 ★★★ 초안 뼈대에서 제외한다.
- **전달**: Google Drive 저장 + Gmail 발송 대신 **로컬 md 파일 저장 + 텔레그램 발송**을 쓴다.
  (Gmail MCP는 초안(draft) 생성만 가능하고 실제 발송 기능이 없어, 클라우드 RemoteTrigger로
  10일간 만든 브리핑이 전부 임시보관함에 안 읽힌 채 쌓여있던 것을 2026-07-26에 발견 —
  `기사검수.py`가 이미 쓰는 텔레그램 봇으로 전환)

### 예전 방식(클라우드 RemoteTrigger) — 은퇴함
2026-07-16~07-26 `소재타임스-기사기획-브리핑`이라는 이름의 RemoteTrigger(`trig_01UTjAo41yX72eMjchDKXJbo`)로
매일 KST 07:00에 클라우드 실행됐다. NaverSearch MCP로 직접 수집(→ collect.py와 중복) +
Google Drive 저장은 정상 동작했으나, Gmail 발송은 초안 생성만 되고 실제 도착하지 않는 문제가 있었다.
2026-07-26 로컬 스크립트로 대체하며 `enabled: false`로 비활성화(삭제는 https://claude.ai/code/routines 에서 가능).

## 아래는 `기사기획브리핑.py`가 실제로 LLM에 보내는 프롬프트의 핵심 내용이다

### 이슈별 기사 기획 분석
수집된 각 이슈에 대해 아래 5가지를 분석:

**[A] 중요도 등급**
| 등급 | 기준 |
|------|------|
| ★★★ | 공급망 직접 충격, 수출규제 신규 발표, 대형 기업 생산 중단/전환 → 즉시 기사화 필요 |
| ★★  | 새로운 기술 개발, 주요 투자/M&A, 정부 R&D 과제 → 이번 주 내 취재 추천 |
| ★   | 시장 동향, 분석 리포트, 학술 연구 → 배경 자료 또는 기획기사 소재 |

**[B] 소재타임스 독자 관점 설명** — 소부장 업계 종사자·연구자·정책 담당자 관점에서
"왜 이 이슈가 지금 중요한가"를 2~3문장으로 설명.

**[C] 기사 각도 제안 (최대 3개)** — 소재타임스 스타일에 맞는 구체적인 기사 방향.

**[D] 추천 취재원 유형** — 인터뷰/확인 취재 대상 유형 제시 (실명 아닌 유형으로).

**[E] 선행 보도 가능성** — "단독 발굴 가능성 높음" / "후속·심층 기사로 차별화 필요" /
"이미 많이 보도됨" / "오늘 소재타임스에 이미 발행됨 — 후속 심화 필요" 중 하나.

### ★★★ 이슈 기사 초안 (긴급 취재 지원)
오늘 미발행 ★★★ 등급 이슈에 대해서만: 기사 제목 후보 3개, 리드 후보, 기사 구성 제안,
필수 확인 사항.

## 주의사항
- 중복 기사 제거 (동일 이슈 다른 매체는 1건으로 통합)
- 단순 주가/시황 기사 제외 (산업 이슈 중심)
- 3일 이상 오래된 기사 제외
- 중국 수출규제 이슈 최우선 체크
- WebFetch 실패 시 건너뛰고 계속 진행
- 기사 각도는 반드시 소재타임스 독자(소부장 업계) 관점으로 작성
- 프롬프트 전문은 `기사기획브리핑.py`의 `build_prompt()` 참고 (이 문서는 스펙 요약본)
